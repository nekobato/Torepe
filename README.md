# Torepe

Torepe: クリップボードやファイルからスクリーン上に画像を固定して表示するためのデスクトップアプリケーションです。実装とデザインを重ねて比較したい時に。

## ダウンロードとインストール

現在の公開版は [v1.6.5](https://github.com/nekobato/Torepe/releases/tag/v1.6.5)（2026年6月14日公開）です。

- [macOS / Apple Silicon 用 DMG をダウンロード](https://github.com/nekobato/Torepe/releases/download/v1.6.5/Torepe-1.6.5-arm64.dmg)
- [すべてのリリース](https://github.com/nekobato/Torepe/releases)

1. Apple Silicon 搭載の Mac で DMG を開きます。
2. 中の `Torepe.app` を「アプリケーション」フォルダにコピーします。
3. コピーした `Torepe.app` を起動します。

この版で公開されている DMG は arm64 向けです。Intel Mac 用の配布物や最低 macOS バージョンは、この案内では保証していません。起動時に警告が出る場合は、配布元とファイル名を確認し、警告の内容を添えて [Issues](https://github.com/nekobato/Torepe/issues) に報告してください。
